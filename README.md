## 🌱 Why FrameForge Exists

Most recording tools assume you want a single monolithic file at the end. FrameForge assumes the opposite: that a recording is raw material for something larger. A QA engineer captures a bug reproduction and needs to attach it to a ticket. A teacher records a math walkthrough and needs to slice it into three short clips. A product team captures a demo and needs captions in four languages before the launch call.

FrameForge was designed around those downstream needs. It records cleanly, then hands you a workspace where trimming, annotating, captioning, and exporting feel as natural as dragging a slider.

The name is deliberate. A forge is not a warehouse — it is a place where raw material becomes finished work. That is exactly the relationship FrameForge has with your screen activity.

---

## ✨ What Makes It Different

A few philosophies run through every corner of the application:

1. **Recording is a project, not a file.** Every capture session gets a project folder with metadata, notes, and a non-destructive edit history.
2. **Nothing is final until you export.** Trims, blur regions, and annotations are stored as instructions, not baked into the source. You can always go back.
3. **Speed is a feature.** Launching a capture should take less time than opening a chat window. FrameForge targets a two-second cold start on modest hardware.
4. **Local-first by default.** Your recordings stay on your disk unless you explicitly hand them off.
5. **The interface adapts to the task.** Capture mode strips away everything but the essential controls. The editor reveals depth on demand.

## 🎥 Capture Modes

FrameForge offers four distinct capture personalities, each tuned for a different situation.

### Region Capture
Drag a rectangle and record only that area. Ideal for capturing a single application panel, a browser viewport, or a specific chart. The region persists between sessions so you can re-record the same area repeatedly.

### Window Capture
Attach the recording to a specific window handle. If the window moves or resizes, FrameForge follows it. This is the mode most people want for tutorial work, because it eliminates the accidental taskbar reveal.

### Full-Screen Capture
Record the entire display. Choose a single monitor or a combined canvas in multi-display setups. A latency-optimized pipeline keeps frame pacing stable even on high refresh panels.

### Focused App Capture
A hybrid mode that records a target application plus a margin of context. Useful when a tutorial needs to show a popup or dialog that appears just outside the main window bounds.

Each mode remembers its own audio configuration, overlay settings, and export preset. Switching modes is a single click, not a configuration ritual.

## 🛠 Post-Recording Workspace

The editor is where FrameForge earns its keep. It is organized into four panes, each collapsible:

| Pane | Purpose |
| --- | --- |
| **Timeline** | Frame-accurate scrubbing, split, ripple delete, and speed ramps |
| **Layers** | Toggle annotations, cursor effects, captions, and audio tracks independently |
| **Inspector** | Fine-tune properties of the currently selected element |
| **Project Notes** | Free-form markdown notes attached to the project, searchable later |

The timeline supports up to 12 annotation layers and 6 audio tracks. Non-destructive editing means you never lose the original source — only the instructions on how to present it.

## ⚡ Performance & Resource Footprint

FrameForge uses hardware-accelerated encoding where available and falls back to a tuned software path otherwise. Benchmarks on a mid-range 2022 laptop show:

- **Idle CPU usage:** under 1%
- **1080p60 capture CPU usage:** roughly 6–9%
- **GPU encoding overhead:** dependent on codec, typically 3–5% on modern integrated graphics
- **Disk throughput:** adaptive bitrate keeps writes efficient without starving other applications

The application is also respectful of battery. On laptops, a power-aware mode reduces capture frame rate when unplugged and the user is not interacting.

## 💻 Getting Started on Windows 11 & 10

FrameForge targets Windows 11 and Windows 10 (version 21H2 or newer). It runs on x64 and ARM64 devices.

Before you begin, confirm:

- Windows is fully updated
- At least 4 GB of RAM (8 GB recommended for 1440p or higher capture)
- Around 500 MB of disk space for the application itself, plus room for recordings
- Optional: a discrete or integrated GPU with hardware encoding support for best performance

## 🧭 Setup Walkthrough

The setup flow is intentionally short. Here is what to expect:

1. **Acquire the installer.** Use the download marker above to obtain the current 2026 release package.
2. **Run the installer.** A standard Windows installer walks you through the destination folder and optional shortcuts.
3. **First launch.** FrameForge opens a short welcome tour you can skip at any time.
4. **Microphone check.** The wizard tests your default microphone and shows a live level meter.
5. **Choose a profile.** Pick from Creator, Educator, Support, or Custom. This sets sensible defaults you can change later.
6. **Set your hotkeys.** The default global shortcut is easy to change if it conflicts with another application.
7. **Record a five-second test.** Confirm everything works before your first real session.

The whole process typically takes under three minutes.

## ⚙️ Configuration Profiles

Profiles bundle capture mode, audio setup, overlay preferences, and export presets into a single switchable entity.

- **Creator Profile:** 1440p60, cursor emphasis on, webcam PiP, MP4 export at high bitrate.
- **Educator Profile:** 1080p30, keystroke overlay on, captions enabled, chapter markers.
- **Support Profile:** 1080p30, region capture, GIF export preset, short clip length.
- **Custom Profile:** start from a blank slate and tune everything yourself.

Profiles can be exported and imported as small configuration files, making it easy to standardize a team's recording habits.

## 🔌 Integrations & Workflow Bridges

FrameForge exposes local integration endpoints that other tools can talk to. This is intentionally minimal and opt-in.

## ❓ Frequently Asked Questions

**Does FrameForge replace my existing editor?**
Not necessarily. Many users record in FrameForge and finish in a dedicated editor. Others never leave FrameForge at all.

**Can I record multiple monitors at once?**
Yes, in full-screen mode with the combined canvas option.

**What happens if my machine sleeps mid-recording?**
Capture pauses and resumes automatically, with a marker placed at the pause point.

**Is there a portable mode?**
Yes, a portable configuration stores everything alongside the application folder.

**Can I recover an interrupted recording?**
Yes. FrameForge writes incrementally, so a crash rarely costs more than a few seconds.

## 📖 Glossary of Recording Terms

- **Bitrate:** the amount of data used per second of video; higher bitrate, higher fidelity, larger file.
- **Frame pacing:** the consistency with which frames are delivered; matters more than raw frame rate for perceived smoothness.
- **Keyframe:** a fully encoded frame used as a reference point for later frames.
- **Non-destructive edit:** a change stored as an instruction rather than applied permanently.
- **Sidecar file:** a companion file that carries metadata for another file.
